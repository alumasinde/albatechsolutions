# SEO, mobile UX and discoverability updates

## Added endpoints

- `/sitemap.xml` is generated by `SeoController` and includes the main public pages plus published service pages in active categories.
- `/robots.txt` allows public pages, disallows `/admin` and `/health`, and points crawlers to the sitemap.
- `/llms.txt` provides a short, factual guide for AI/automated systems. It does not guarantee indexing or AI citations.

## On-page SEO

- Canonical URL, description, robots directives, Open Graph and Twitter summary metadata are emitted from the shared public layout.
- Organization structured data is emitted for general pages; service pages emit Service structured data.
- Admin pages already use `noindex,nofollow`.
- Font Awesome remains loaded from the CDN; the public Content Security Policy allows the CDN stylesheet and font resources.

## Production checklist

1. Set `APP_URL` and the public `site_url` setting to the canonical HTTPS domain, without a trailing slash if possible.
2. Confirm the service catalogue and every published service page return HTTP 200.
3. Open `/sitemap.xml`, `/robots.txt`, and `/llms.txt` in a browser and verify the URLs use the real production domain, not `.test`.
4. Submit the sitemap in Google Search Console and Bing Webmaster Tools after DNS and HTTPS are configured.
5. Test the homepage, services, service detail and contact flows at 320px, 375px, 768px and desktop widths.
6. Confirm Font Awesome is allowed by the production CSP and that the icon stylesheet loads successfully.
7. Validate structured data with a schema validator and inspect canonical URLs for duplicate/trailing-slash variants.
8. Configure a real social preview image and add its absolute HTTPS URL to `og:image` / `twitter:image` once a suitable brand image exists.
9. Check Lighthouse/Core Web Vitals against the live site. Source changes alone do not establish a performance score.

## Notes

- Sitemap generation falls back to the core public pages if the database is temporarily unavailable; published service URLs are included when the database query succeeds.
- Sitemap `changefreq` and `priority` are hints, not crawl guarantees.
- `llms.txt` is an emerging convention, not a replacement for structured data, sitemap, robots policy or useful original content.
- This update does not claim a 10/10 or guarantee search ranking. Search visibility depends on live configuration, content quality, links, crawlability and performance.
